Why monaco-json-studio-single Exists

1-pane Monaco JSON Studio (v5) with --url loading, visual source badges, Render button, and BroadcastChannel sync.

Design Story

In a 1-pane editor, stacking a separate pane header below the studio bar wastes vertical space—and just showing JSON without rendering DOM leaves half the workflow unfinished.

In v5, monaco-json-studio-single composes base-header (v2), base-body (v3), and base-footer (v1), displays live source badges (LOCAL DATA, SAME SERVER, REMOTE URL, LOCAL FILE, LOAD FAILED), and adds a Render button that broadcasts JSON via BroadcastChannel and localStorage to monaco-json-studio-preview.
