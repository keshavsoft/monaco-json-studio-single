Why monaco-json-studio-single Exists

1-pane static Monaco JSON Studio generator composing base-header, base-body, and base-footer.

Design Story

In a 1-pane editor, stacking a separate pane header below the studio bar wastes vertical space.

monaco-json-studio-single (v4) directly composes monaco-json-studio-base-header, monaco-json-studio-base-body (v3), and monaco-json-studio-base-footer through document.hbs, splitting Monaco into dedicated js/monaco/ modules (loader, source, mount, value, events).

The top-right source pill clearly identifies where the displayed JSON originated: LOCAL DATA (amber), SAME SERVER (cyan), REMOTE URL (indigo), LOCAL FILE (green), or LOAD FAILED (red).
