Dependencies & Ecosystem

What monaco-json-studio-single builds on and where it is used.

Direct Dependencies

  • handlebars (^4.7.10) — Compiles assets/v5/templates/document.hbs.
  • monaco-json-studio-base-header (v2) — Provides header .hbs rendering with extraButtons (Render) and dom-primitive-bindings.
  • monaco-json-studio-base-body (v3) — Provides the 1-pane workspace and modular js/monaco/ runtime with URL/source detection.
  • monaco-json-studio-base-footer (v1) — Provides footer .hbs rendering and cursor/stats updaters.

Used By

  • Standalone JSON studios paired with monaco-json-studio-preview over BroadcastChannel
